# Code of Conduct

We want OpenBot to be a welcoming project for everyone.

- Be kind and assume good intent.
- Critique ideas, not people.
- No harassment, discrimination or personal attacks.
- Help newcomers. Everyone started somewhere.

Maintainers may remove comments, commits or contributors that break these rules. To report a problem, open a private security advisory or contact the maintainers.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
